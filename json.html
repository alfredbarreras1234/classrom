JSON

¿Qué es JSON y por qué es el estándar?

JSON (JavaScript Object Notation) es un formato de texto ligero para intercambiar datos. Es el estándar porque es fácil de leer para humanos, simple de procesar para las máquinas, independiente del lenguaje y nativo en JavaScript.

Estructura

  • Clave-valor: "nombre": "Ana". La clave siempre va entre comillas dobles.
  • Objetos: conjuntos de pares clave-valor entre llaves { }.
  • Arreglos: listas ordenadas entre corchetes [ ].
  • Valores permitidos: cadena, número, booleano, null, objeto y arreglo.

Objeto JS vs Cadena JSON

// Objeto JavaScript
const alumno = {
  nombre: 'Ana',
  edad: 17,
  materias: ['HTML', 'CSS', 'JS']
};

// Cadena JSON (texto)
const texto = '{"nombre":"Ana","edad":17,"materias":["HTML","CSS","JS"]}';

// Conversión
const aTexto = JSON.stringify(alumno);
const aObjeto = JSON.parse(texto);
console.log(aObjeto.nombre);

Comunicación con APIs y servidores

El navegador (cliente) envía una petición a una API y el servidor responde normalmente con JSON. Después, el cliente convierte ese texto en objeto y lo muestra en la página.

fetch("https://api.ejemplo.com/usuarios")
  .then(function (respuesta) { return respuesta.json(); })
  .then(function (datos) { console.log(datos); })
  .catch(function (error) { console.error(error); });
