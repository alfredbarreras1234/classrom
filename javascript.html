JavaScript Vanilla

Concepto

JavaScript Vanilla es JavaScript puro: el lenguaje estándar del navegador usado sin librerías ni frameworks como jQuery, React o Vue. Permite que una página reaccione al usuario, modifique su contenido y se comunique con servidores.

El trinomio HTML, CSS y JS

HTML

Define la estructura y el contenido: títulos, párrafos, formularios, imágenes.

CSS

Define la presentación: colores, tipografías, espacios y diseño responsivo.

JS

Define el comportamiento: interacciones, validaciones y datos dinámicos.

Variables, funciones y eventos

  • Variables: guardan datos. Se declaran con let (valor cambiable) o const (valor constante).
  • Funciones: bloques de código reutilizables que pueden recibir parámetros y devolver un resultado.
  • Eventos: acciones del usuario (clic, teclado, envío de formulario) que se capturan con addEventListener.

Ejemplo de código

// Variables
const nombre = "CodeSphere";
let visitas = 0;

// Función
function saludar(usuario) {
  return "Hola, " + usuario + " bienvenido a " + nombre;
}

// Evento
document.getElementById("btn").addEventListener("click", function () {
  visitas++;
  alert(saludar("Alfred") + " - clics: " + visitas);
});
